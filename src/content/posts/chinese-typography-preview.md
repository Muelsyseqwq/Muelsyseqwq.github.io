这是一篇专门用来观察博客中文排版效果的文章。正文使用 **霞鹜文楷**，导航、日期和按钮等界面元素继续使用思源黑体，代码则交给独立的等宽字体。

## 中文正文与标点

好的中文网页排版不只是“换一种字体”。字重、行高、段落间距和标点都会影响阅读节奏。比如：“春风又绿江南岸，明月何时照我还？”这句话包含逗号、问号与引号，可以用来观察标点的位置和字面大小。

霞鹜文楷的笔画比普通无衬线字体更有书写感，但又不会像传统楷体那样过于正式。它适合随笔、学习笔记和长篇中文正文；较短的导航文字仍使用黑体，辨识速度会更好。

> 字体不是页面的装饰品，而是内容被阅读时所经过的界面。

## 中英文混排

AstroPaper is a clean and minimal blog theme. 当 English、数字 0123456789、缩写 API，以及中文出现在同一段落时，需要注意基线、字符宽度和空格是否自然。

常见技术词汇包括 `Astro`、`TypeScript`、`CSS` 和 `font-family`。行内代码应该保持等宽，同时又不能打断中文句子的阅读节奏。

## 列表与强调

这套字体方案的分工如下：

1. 界面和导航使用思源黑体，保持清晰利落。
2. 文章正文使用霞鹜文楷，提高中文长文的阅读感。
3. 代码使用 Cascadia Code、Consolas 等等宽字体。
4. 字体文件随网站部署，不依赖运行时访问 Google Fonts。

需要特别检查 **粗体强调**、链接样式和较长段落。在手机屏幕上，正文应当自然换行，不应出现异常的字符重叠或横向滚动。

## 表格测试

| 内容类型 | 使用字体 | 推荐字重 |
| --- | --- | ---: |
| 导航与按钮 | 思源黑体 | 400–600 |
| 中文正文 | 霞鹜文楷 | 400 |
| 小标题 | 霞鹜文楷 | 500 |
| 代码 | 等宽字体 | 400 |

## 代码块测试

```ts
const typography = {
  interface: "Noto Sans SC Variable",
  article: "LXGW WenKai",
  code: "Cascadia Code",
};

console.log("中文字体加载完成", typography);
```

## 生僻字与回退

字体切片不一定覆盖所有罕见字符。遇到“𠮷、珏、燚、龘”等字时，浏览器会按照字体栈自动回退；只要字符仍能正常显示，就说明回退配置有效。

最后再放一段连续文字观察整体灰度：清晨的风从窗边经过，桌上的书翻开了一页。屏幕里是尚未写完的程序，杯子里的茶已经微凉。技术博客记录的不只是答案，也记录寻找答案时走过的路。
